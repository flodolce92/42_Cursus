## 📝 Project Descriptions
- **Libft**: A custom C library that includes various utility functions, such as string manipulation, memory management, and more. This project is a fundamental building block for many other projects in the 42 curriculum.

- **ft_printf**: A custom implementation of the printf function in C, which formats and prints data to the standard output. This project helps students understand variadic functions and format specifiers.

- **get_next_line**: A function that reads a line from a file descriptor, handling multiple file descriptors and dynamic memory allocation. This project teaches students about file I/O and memory management in C.

- **Born2BeRoot**: A Linux server configuration project that introduces students to basic system administration using VirtualBox and Debian. Tasks include setting up users, SSH, UFW firewall, and monitoring tools.

- **pipex**: A project that implements a command-line utility that allows users to execute multiple commands in a pipeline, similar to the Unix shell. This project focuses on process management and inter-process communication.

- **so_long**: A 2D game project that involves creating a simple game using the MiniLibX graphics library. Students learn about game loops, event handling, and basic graphics rendering.

- **push_swap**: A sorting algorithm project that requires students to implement a sorting algorithm for a stack of integers. The goal is to sort the stack using the least number of operations possible.

- **minishell**: A simple shell implementation that mimics the behavior of the Unix shell. This project covers parsing, executing commands, and handling environment variables.

- **philosophers**: A concurrency project that simulates the dining philosophers problem using threads and mutexes. Students learn about synchronization, deadlock prevention, and resource management.

- **cub3D**: A 3D game engine project that involves creating a simple 3D game using raycasting techniques. Students learn about graphics rendering, game physics, and user input handling.

- **NetPractice**: An interactive learning tool where students configure networks (IP, routing, subnets) to understand basic networking concepts hands-on.

- **CPP Modules 00-04**: A series of projects that introduce students to C++ programming, covering topics such as classes, inheritance, polymorphism, and templates.
